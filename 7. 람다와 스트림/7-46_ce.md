# 스트림에서는 부작용 없는 함수를 사용하라.

## 스트림 패러다임
- 스트림 패러다임의 핵심은 계산을 `일련의 변환`으로 재구성한다는 부분이다.
- 각 변환 단계에서는 `이전 단계의 결과`를 받아 `순수 함수`로 처리한다.
  - 순수 함수: 오직 입력만이 결과에 영향을 주는 함수
    - 다른 가변 상태를 참조하지 않음
    - 함수 스스로 다른 상태를 변경하지 않음

스트림 연산에 건네는 함수 객체는 모두 부작용(side effect)이 없어야한다.

### 잘못된 스트림의 예시
```java
Map<String, Long> freq = new HashMap<>();
try(Stream<String> words = new Scanner(file).tokens()) {
  words.forEach(word -> {
    freq.merge(word.toLowerCase(), 1L, Long::sum);
  });
}
```
- 해당 코드는 스트림을 가장한 반복적 코드이다.
- forEach는 `스트림 연산 결과`를 보여줄 때만 사용하자. 연산에 사용 하지 말자.
- forEach 내부에서 람다를 실행하고 있으므로 순수 함수가 아니다.


### 스트림을 제대로 활용한 경우
```java
Map<String, Long> freq;
try(Stream<String> words = new Scanner(file).tokens()) {
  freq = words.collect(groupingBy(String::toLowerCase, counting()));
}
```


## Collectors
- `stream.Collectors`: 수집기라고 부르며 스트림에서 꼭 알아야할 개념
- 수집기를 사용하면 스트림의 원소를 컬렉션으로 쉽게 모을 수 있다.
    - `toList()`, `toSet()`, `toCollection(collectionFactory)`
- <b>최종 처리 (스트림 종료 작업)</b>으로 주로 쓰임

### toList()
```java
List<String> topTen = freq.keySet().stream()
  .sorted(comparing(freq::get).reversed())
  .limit(10)
  .collect(toList());
```
- 가장 흔한 단어 10개를 뽑아내는 파이프라인

### toMap()
```java
private static final Map<String, Operation> stringToEnum = Stream.of(values()).collect(toMap(Object::toString, e-> e));
```
- 키가 고유할 때만 사용 가능한 코드
- 키가 중복되면 IllegalStateException 발생

```java
private Map<Artist, Album> topHits = albums.collect(
    toMap(Album::artist, a->a, maxBy(comparing(Album::sales))));
```
- 인수 3개를 받는 toMap은 키와 그 키에 연관된 원소들 중 하나를 골라 맵을 만들 때 유용하다.
- 인수 3개를 받는 toMap은 충돌이 나면 마지막 값을 취하는 수집기를 만들 때 유용하다.

    ```java
    toMap(keyMapper, valueMapper, (oldVal, newVal) -> newVal);
    ```

### groupingBy
- 입력: 분류 함수
- 출력: 원소들을 카테고리별로 모아 놓은 맵을 담은 수집기를 반환
  - 카테고리 = 맵의 key

```java
words.collect(groupingBy(word -> alphabetize(word)));

// 출력값
Map<String, List<String>>

//출력값 예시
{
    "act" -> ["cat", "tac", "act"],
    "dgo" -> ["dog", "god"]
}
```
- groupingBy가 반환하는 수집기(collector)가 리스트 값을 가짐
- 리스트 외의 값을 갖게 하기 위해서는 분류 함수와 함께 `다운스트림 수집기`도 명시해야 한다.
    - toSet(), toCollection(collectionFactory), counting()
    
    ```java
    // counting()을 통해 List 타입을 Long으로 바꿔줌
    Map<String, Long> freq = words.collect(groupingBy(String::toLowerCase, counting()));
    ```

    - 그 외에도 맵 팩토리도 지정할 수 있다.
    - groupingByConcurrent

### partitioningBy
- 분류 함수 자리에 predicate를 받고, 키가 Boolean인 맵을 반환

### maxBy, minBy
- 인수로 받은 비교자를 통해 스트림에서 가장 값이 작은/큰 원소를 반환

### joining
- CharSequence 인스턴스의 스트림에만 적용 가능
- 단순히 원소들을 연결하는 수집기를 반환
- 인수 3개짜리 joining은 접두문자, 구분문자, 접미문자를 인수로 받는다.
<br/> ex) joining("[", ",", "]");
