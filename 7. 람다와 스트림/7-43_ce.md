# 람다보다는 메서드 참조를 사용하라.

- 함수 객체를 람다보다 간결하게 만드는 방법으로 메서드 참조가 있다.
- 람다로 구현했을 때 너무 길거나 복잡하다면 메서드 참조가 좋은 대안이 될 수 있다.

```java
// 람다를 사용한 경우
map.merge(key, 1, (count, incr) -> count+incr);

// 메서드의 참조를 사용하는 경우
map.merge(key, 1, Integer::sum);
```

### 메서드 참조 유형
1. 정적
2. 한정적 - 수신 객체를 특정
3. 비한정적
4. 클래스 생성자
5. 배열 생성자
