# 표준 함수형 인터페이스를 사용하라

- 직접 구현하기 보다는 이미 존재하는 자바 표준 함수형 인터페이스를 사용하자.
-> `java.util.function`

## java.util.function 패키지
총 43개의 인터페이스가 존재한다. 그 중에서 기본 인터페이스 6개만 기억하고 나머지는 유추해서 사용하자.

### 인터페이스 종류
- `Operator`: 인자와 반환값 타입이 같은 함수
  - `UnaryOperator`: 인자 1개
  - `BinaryOperator`: 인자 2개
- `Predicate`: 인자 1개 + boolean을 반환
- `Function`: 인자와 반환 타입이 다른 함수
- `Supplier`: 인자를 받지 않고 값을 반환(혹은 제공)
- `Consumer`: 인자 1개 + 반환값이 없음(혹은 인자를 소비)

기본 인터페이스는 기본 타입인 int, long, double 용으로 3개씩 변형이 생긴다.<br>
ex) Predicate -> IntPredicate, LongPredicate, DoublePredicate

### Function
이 중에서 유일하게 Function만 매개변수화 변형을 한다.<br>
입력과 결과 타입이 모두 기본이라면 `SrcToResult`를 사용하고 입력이 객체 참조이고 결과가 기본 타입이면 `ToResult` 방식을 사용한다.

```
// 입력과 결과 타입이 모두 기본
LongToIntFunction -> 입력이 long, 결과가 int 타입
ToLongFunction -> 입력이 int[], 결과가 long
```

### 특징
- 표준 함수형 인터페이스의 대부분은 기본 타입만 지원한다. 그러므로 함수형 인터페이스에 박싱된 기본 타입은 넣지 말자. 성능이 매우 안 좋다.

### 표준 함수형 인터페이스를 사용하지 않는 경우
구조적으로 똑같은 인터페이스가 있더라도 아래와 같은 경우에는 직접 코드를 작성하는 것을 권장한다.
- 자주 쓰이며, 이름 자체가 용도를 명확하게 말해줄 때
- 반드시 따라야하는 규약이 있을 때
- 유용한 디폴트 메서드를 제공할 때

그리고 직접 만든 함수형 인터페이스에는 항상 `@FunctionalInterface` 애너테이션을 사용하자.
