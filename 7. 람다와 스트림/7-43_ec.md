# 람다보다는 메서드 참조를 사용하라
람다가 익명 클래스보다 나은 점 중 하나는 간결함이고 람다보다 더 간결한 메서드 참조가 있다.

```java
map.merge(key, 1, (count, incr) -> count + incr);
```

메서드 참조를 이용하면 다음과 같이 나타낼 수 있다.

```java
map.merge(key, 1, Integer::sum);
```

매개변수가 늘어날 수록 메서드 참조로 제거할 수 있는 코드양도 늘어난다.

IDE에서는 대부분 메서드 참조를 사용하도록 유도한다. 하지만 항상 좋은 것은 아니다. 

```java
service.execute(GoshThisClassNameIsHumougous::action);
```

이를 람다로 대체하면 다음처럼 된다.

```java
service.execute(() -> action());
```

정리하면 메서드 참조는 람다의 간단명로한 대안이 될 수 있지만 람다가 더 간결할 경우 람다를 사용하자.
