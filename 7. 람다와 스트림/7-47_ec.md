# 반환 타입으로는 스트림보다 컬렉션이 낫다
Stream 인터페이스는 Iterable 인터펟이스가 정의한 추상 메서드를 전부 포함하지만 for-each 를 지원하지 않는다.

Stream의 iterator 메서드에 건네면 가능하긴 하다.

```java
public static <E> Iterable<E> iterableOf(Stream<E> stream) {
	return stream::iterator;
}
```

만약에 스트림 파이프 라인만 사용한다면 스트림을 반환하고 반복문을 사용한다면 Iterable 타입으로 반환하자. 
하지만 공개 API를 작성한다면 스트림과 반복문을 사용하려는 사람 모두를 배려해야 한다.

Collection 인터페이스는 Iterable 하위 타입이고, stream 메서드도 제공한다. 

따라서 메모리에 올려도 될만큼 큰 사이즈가 아니라면 표준 컬렉션에 담아서 반환하고 컬렉션이 불가능하면 스트림과 Iterable 중 더 자연스러운 것을 반환한다.
